# Mobile app scope

- Keep Student, Parent, and Finance frontend work in this directory using JavaScript (`.js`) and JSX (`.jsx`) only.
- Do not edit existing `.ts` or `.tsx` files or shared project configuration for this scope.
- Prefer reusable, accessible React Native components and keep screen data behind service modules.
- If integration requires changes outside `src/mobileApp/`, provide a separate snippet and explain where it belongs; do not apply it.
- Verify changes with focused checks that do not require changing shared configuration.
